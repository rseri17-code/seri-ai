Operational memory is the accumulated context that helps an enterprise understand recurring work: incidents, decisions, dependencies, transaction journeys, mitigations, owners, and known failure modes.

Without memory, every investigation starts from zero. With memory, AI systems can compare the current situation against known patterns while still respecting evidence and uncertainty.

The goal is not to automate judgment away from people. The goal is to preserve context so human decisions get better over time.

Each investigation should leave the dynamic map more complete. Newly discovered components become nodes, and observed dependencies become edges. Validated causal relationships carry supporting evidence and the conditions under which they hold. Untested explanations remain hypotheses.

When a node fails again, the agent starts with those dependencies and findings, checks what changed, and challenges relationships that no longer hold. The harness should retain evidence references and validation results so reusable knowledge stays testable.
